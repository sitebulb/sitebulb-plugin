# Dev Handoff

Turns Sitebulb audit findings into dev-ready tickets in your connected PM tool (Jira, Linear, Asana, Monday, or ClickUp): one ticket per selected issue, carrying what's wrong, why it matters, the true affected-URL count with labelled sample URLs, a suggested fix with its knowledge-base link, acceptance criteria, severity-mapped priority, and an effort estimate. Every draft is previewed in chat before anything is created.

**Invoke with:** "send these to Jira", "ticket the quick wins", "make Linear issues for these", "hand the 404s to the devs".

**Needs:** a connected Sitebulb Desktop or Cloud MCP with a finished audit. A PM-tool MCP enables direct ticket creation; without one, the skill produces ready-to-paste markdown ticket bodies instead.

**Hands off to:** `what-to-fix-first` for true impact-vs-effort prioritisation before ticketing.
