# What To Fix First

Prioritised triage of a Sitebulb audit: the 3–5 issue clusters most worth fixing for *your* business in *your* situation. The skill interviews for context (business type, situation, constraints, role), sweeps the audit's triggered hints, scores impact against effort with a deterministic scorer, and delivers a conversational read with evidence cards — impact framed in plain consequences, effort as owner, size, and indicative duration.

**Invoke with:** "what should I fix first", "what's wrong with this site", "prioritise this audit", "quick wins".

**Needs:** a connected Sitebulb Desktop or Cloud MCP with a finished audit. Google Analytics / Search Console connected inside Sitebulb sharpens the ranking with real traffic data (optional).

**Hands off to:** `dev-handoff` (raise tickets), `technical-seo-audit` (client document), `what-changed` (change over time).
